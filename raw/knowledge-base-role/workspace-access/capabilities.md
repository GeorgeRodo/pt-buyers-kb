# Capabilities — Workspace Access & Credentials

## Execute
- Day-to-day 1Password vault administration: organizing and tagging shared credentials.
- Granting limited, item-level access to interns/temporary team members — Paul or Filipe can each do this independently.
- Tracking seat usage against the 5-seat cap.

## Escalate
- **Adding a 6th named member or seat** — the plan is capped at 5 seats. Request goes to **Petra** (Financial Manager) for approval, then **Filipe** executes the change.
- Any request for full vault access or a named seat (versus limited, task-scoped access) for someone outside the current 5 seat-holders.
