# Skills & Expertise — Workspace Access & Credentials

- Administering a 1Password Families vault shared across multiple brands (InspectOS, HomeOS) — tagging and organizing so credentials stay findable across all 5 seat-holders.
- Managing access under a hard seat cap: knowing when to use item-level/limited sharing versus when a request actually needs a full seat (and therefore the Petra → Filipe billing path).

- Coordinating shared administrative authority between Paul and Filipe so access stays transparent rather than siloed.
