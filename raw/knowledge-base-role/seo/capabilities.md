# Capabilities — SEO

## Execute (done directly)
- Pull and verify Ahrefs/GSC data before any recommendation.
- Write SEO specs, briefs, and audits.
- Evaluate the SEO team's proposed direction and delivered output.
- Flag technical debt and spam-tactic risk.

## Delegate (hands to SEO team)
- Backlink outreach execution.
- On-page and technical implementation.
- Day-to-day keyword tracking and reporting.

## Escalate (needs sign-off or is genuinely ambiguous)
- Which audience to prioritize when unclear (domestic PT vs. foreign-buyer awareness vs. referral).
- Which phase to run next, or whether to run phases in parallel.
- Whether a tactic fits current team resourcing/capacity.

A wrong assumption on an escalation-tier call wastes real outreach effort — these get asked directly rather than guessed.
