# Skills & Expertise — SEO

- Reading and interpreting backlink/authority data (DR, referring domains, anchor text patterns) to judge prospect quality.
- Spotting manipulative link patterns (PBNs, link farms, suspicious domain clusters) versus legitimate authority-building.
- Matching audience-targeting filters to the actual goal — knowing when PT-only organic traffic is the wrong filter for a foreign-buyer-awareness objective.
- Technical SEO literacy: identifying crawl issues, broken links, orphaned pages, and other on-site debt from a site audit.
- Phase sequencing: recognizing what counts as foundation work (technical cleanup, base content) versus scaling work (backlink acquisition, PR) versus compounding work (sustained authority plays), and not jumping ahead.
- Brief-writing and audit-writing at a level a team/manager can execute against with minimal clarification.
