# Building a comparable set

The comparable set is built in [[phase-2-sourcing|Phase 2]] and cashed in [[phase-6-offer-cpcv|Phase 6]] — it is the written justification behind every offer.

## Method (playbook Ch. 3.1)

1. Pull 12–24 months of registered transactions in the target micro-market (Casa Pronta portal or lawyer/notary contacts).
2. Filter: property type, size band ±20%, discernible condition.
3. Adjust: orientation, floor, view, lift, parking, condition, time-of-sale → price-per-m² range.
4. Test: any asking price 10%+ above the comparable ceiling requires explicit seller-side justification.
5. Document in the buyer dossier.

Transaction data > asking data, always: asking prices are marketing, registered prices are evidence.
