# Property types — hub

The eight phases of [[buyer-journey|the buyer journey]] apply to every transaction; what changes radically across property types is the *content* of each phase — search criteria, viewing checklist, DD documents, specialists engaged, negotiation tactics, and post-purchase priorities. Playbook Ch. 10 profiles six property types against a consistent template. This hub exists so that a single search-criteria page ([[sourcing-strategy]]) or DD stream page ([[phase-4-due-diligence]]) doesn't have to carry six incompatible checklists inline — see the atomicity rule in `CLAUDE.md`.

[[platform-buyers-agency]] previously claimed a seventh "high-yield" type; corrected 2026-07-14 to match the six the playbook actually defines (see that page's changelog note).

## The six types

| Type | Typical buyer | DD intensity | Top red flag | Specialists required |
|---|---|---|---|---|
| [[property-type-historical\|Historical / pre-1950]] | Lifestyle, character-seeking | Very high | Heritage restrictions; structural cracks | Heritage architect; structural engineer; IGESPAR |
| [[property-type-new-build-off-plan\|New build / off-plan]] | Investor; turnkey buyer | Medium (developer DD) | Developer default; handover delay | Lawyer (developer DD); snagging surveyor |
| [[property-type-land-development\|Land / development]] | Self-builder; developer | Very high (urbanistic) | Non-buildable; no access; no utilities | Surveyor; topographer; architect; urbanistic lawyer |
| [[property-type-luxury\|Luxury (€1.5m+)]] | HNW; international; lifestyle | High (title; tax; privacy) | Title complexity; hidden encumbrances | Senior lawyer; tax advisor; security consultant |
| [[property-type-resale-traditional\|Resale / traditional]] | Family; first-time; investor | Medium (condominium; condition) | Condo reserve inadequacy; unpermitted works | Surveyor; condo administrator (enquiry) |
| [[property-type-rural-quinta\|Rural / quinta / farm]] | Lifestyle retirement; rural investor | Very high (water; access; forestry) | No water rights; no access; no habitational licence | Agricultural lawyer; surveyor; hydrologist |

## How this feeds the spine

- **Phase 2 ([[phase-2-sourcing]]):** search-criteria tuning by type — the criteria for a 2-bed Príncipe Real apartment and a 5-hectare Alentejo quinta cannot share a template.
- **Phase 3 ([[phase-3-viewings]]):** each type has additional viewing-checklist items layered on top of the general checklist — see [[agency-checklists]] §B.2.
- **Phase 4 ([[phase-4-due-diligence]]):** each type has distinctive DD dimensions and document requirements — see [[agency-checklists]] §B.3.
- **Phase 6 ([[phase-6-offer-cpcv]]):** negotiation tactics and typical discount ranges are type-specific (3–5% on prime luxury vs. 15–25% on constrained land).
