# Market intelligence system

A defensible, continuously-updated picture of the target segment. Portal-only analysis is structurally biased: portals show **asking** prices and miss the 15–35% of transactions done off-market or developer-direct.

## Required components (playbook table 3.1)

| Component | Source | Cadence |
|---|---|---|
| Asking-price inventory | Idealista, Imovirtual, Casa Sapo, remax.pt | Weekly |
| Transaction prices | INE monthly; Casa Pronta (Portal das Finanças); lawyer/agent networks | Monthly |
| Time-on-market & absorption | Portals + agent network | Monthly |
| New-build supply pipeline | Municipal licences; developer releases | Quarterly |
| Demand indicators | Tourism, residence permits, BdP mortgage approvals | Quarterly |
| Rental / AL performance | RNAAL registry; booking-platform data | Quarterly |
| Regulatory changes | IMPIC, BdP, AT, Câmaras | Continuous |
| Macro backdrop | BdP, Eurostat, INE | Quarterly |
