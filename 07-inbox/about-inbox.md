# Inbox

Temporary parking for material that clearly belongs in the vault but hasn't been classified yet — a half-formed note, a snippet awaiting a proper page, a source not yet ingested into `raw/`. Nothing lives here permanently.

Rule: every lint pass must attempt to empty this folder — file each item into its proper home or delete it. An item still here after two lint passes gets escalated to Paul with a filing proposal.
