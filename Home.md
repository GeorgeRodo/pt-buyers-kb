# Portugal buyer-side knowledge base

One venture, one thesis: **the Portuguese real estate market is structurally tilted toward the seller, and the buyer's side is underserved.** The listing agent works for the seller (DL 118/2013), the state stopped inspecting new builds (*Simplex*, DL 10/2024), and hidden-defect liability now runs on brutal 30-day clocks (DL 67/2023). Every product this venture builds sells protection inside that gap.

## The logic of the project

```
        THE BUYER JOURNEY (the ecosystem, decomposed)
  P1 → P2 → P3 → P4 → P5 → P6 → P7 → P8
  onboard sourcing viewings DUE-DIL finance offer/CPCV closing post-purchase
                     │        │
                     │        └── inspection platform lives HERE
                     │
        ┌────────────┴─────────────┐
        ▼                          ▼
  PLATFORM 1                 PLATFORM 2
  Buyer's Agency             Home Inspection
  (spans P1–P8)              (P3–P4 + post-CPCV)
        ▲                          ▲
        └───────── fed by ─────────┘
  DOMAIN KNOWLEDGE: legal · construction pathology · market intel · regional geology
```

Home inspection is deliberately **not** the root of this knowledge base. The buyer's side is decomposed first; inspection emerges as the technical due-diligence slice of that decomposition. See [[inspection-in-the-buyer-journey|why inspection is a subset, not the frame]].
