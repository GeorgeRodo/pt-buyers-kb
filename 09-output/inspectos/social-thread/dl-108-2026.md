# Thread — "August 3, 2026: the deed stops checking for a habitation license"

**1/**
From 3 August 2026, DL 108/2026 removes the requirement to produce a *licença de utilização* (habitation license) to execute a property deed in Portugal. A notary now just declares whether an urban title exists, is claimed without proof, or is admitted absent. That's it.

**2/**
This is phase two of the same Simplex reform that already removed state technical inspection of new builds (DL 10/2024). Phase one deregulated construction quality checks. Phase two deregulates the documentary check at the point of sale.

**3/**
The mechanism that makes this dangerous: municipal silence for 20/30/45 days now constitutes tacit approval. But *fiscalização administrativa* — physical enforcement — never expires. A tacitly-approved project can still be embargoed or ordered demolished years later.

**4/**
Solidary liability under the republished Art. 100-A RJUE puts promoter, owner, designer, and work director jointly on the hook — fines up to €450,000 for legal entities. When the contractor dissolves (Portugal's "phoenix company" pattern), the fine lands on whoever is still solvent. Usually the owner.

**5/**
Reconstruction is narrowly defined: same footprint, same height, same volume, or it's legally an "extension" requiring full regularization. This gives a hard statutory edge to exactly the flip-detection pattern we already document field-side.

**6/**
Net effect: a three-tier market. Gold-standard compliant properties command a 5–10% premium. Tacit-approval properties carry a 3–8% discount. Undocumented properties trade 20–40% below market, cash-only. Knowing which tier a listing sits in is now a pre-CPCV technical question, not a paperwork formality.

**7/**
Banks are becoming the *de facto* regulator the law tried to remove — lenders can still demand license-equivalent documentation for collateral risk even though the deed no longer requires it. For mortgage-dependent buyers, this means more private due diligence, not less.
